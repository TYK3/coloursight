# ColourSight submission pack

Product docs for ColourSight, built for the colour-blindness hackathon (deadline Friday 6 November 2026).

- [demo-script.md](demo-script.md) – about 2:30 demo script with timestamps, spoken lines and on-screen actions
- [devpost-draft.md](devpost-draft.md) – Devpost copy, DRAFT for Young to review and submit

The camera pages (`app/camera/`, `app/live/`) need a real webcam and permission, so there are no screenshots of them. See the demo script for how to show them live.
