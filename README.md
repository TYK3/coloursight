# ColourSight

Personalised colour-vision test plus live camera correction. Static web, no backend.

## Run

```bash
python3 -m http.server 8000
```

Open http://localhost:8000/app/

## Features

- Colour vision screening test with typed result
- Personalised deficiency profile
- Settings (persist profile)
- Static image before/after preview
- Live camera correction

See `docs/product/` for screenshots, demo script, and Devpost draft (Young submits Devpost).

Migrated from the ColourBlind hackathon work on TYK3/team-board.
